# Data Analyst Job Market Analysis

## Introduction

This project analyzes the Data Analyst job market using real-world job posting data. The objective is to identify the most in-demand skills, highest-paying skills, and the skills that provide the best balance between job demand and salary.

SQL Queries? Check them out here: [project_sql folder](/project_sql/)

## Background

The demand for Data Analysts continues to grow across industries, but not every skill offers the same career value. This project explores a dataset of job postings to answer questions about salary trends, skill demand, and the technologies employers value most.

The project focuses on:

* Most in-demand skills for Data Analysts
* Highest-paying skills
* Highest-paying Data Analyst jobs
* Skills with the best combination of demand and salary

## Tools I Used

* PostgreSQL for database management
* SQL for data querying and analysis
* SQLTools for running SQL inside VS Code
* VS Code as the development environment
* Git & GitHub for version control
* CSV files as the source dataset

## The Analysis

### Most In-Demand Skills

The analysis found that SQL is the most requested skill, followed by Excel, Python, Tableau, and Power BI. These technologies consistently appear across thousands of job postings, making them essential skills for Data Analysts.

### Highest-Paying Skills

While SQL and Python dominate demand, specialized tools such as PySpark, Pandas, Databricks, Bitbucket, and DataRobot are associated with significantly higher average salaries. These skills appear less frequently but often correspond to more advanced roles.

### Highest-Paying Jobs

Senior and leadership positions offered the highest salaries in the dataset. Roles such as Director of Analytics, Associate Director of Data Insights, and Principal Data Analyst consistently exceeded $180,000 per year, with the top salary reaching $650,000.

### Optimal Skills

By combining salary and demand, SQL and Python emerged as the strongest overall career investments. Tableau and Power BI also showed an excellent balance between market demand and competitive salaries, making them valuable complementary skills.

## Conclusions

The analysis shows that SQL remains the foundation of a Data Analyst career, while Python, Tableau, Excel, and Power BI provide strong opportunities across the job market. Specialized technologies such as PySpark, cloud platforms, and advanced data engineering tools can significantly increase salary potential as professionals move into more senior roles.

Overall, this project demonstrates how SQL and PostgreSQL can transform raw job posting data into meaningful career insights that help guide learning and professional development.
